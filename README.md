## 🚀 Projeto em destaque

### 🔹 FlowHub — Plataforma SaaS de gestão empresarial

Plataforma de gestão e agendamento desenvolvida para atender diferentes tipos de negócios, com foco em organização, produtividade e relacionamento com clientes.

O projeto evoluiu de uma aplicação voltada para pet shops para uma estrutura mais flexível, preparada para atender diferentes segmentos comerciais.

#### 🏗️ Arquitetura e desenvolvimento

* Backend desenvolvido com NestJS e TypeScript.
* Frontend desenvolvido com Next.js e React.
* Arquitetura modular, organizada por funcionalidades e responsabilidades.
* Banco de dados PostgreSQL com Prisma ORM.
* Arquitetura multi-tenant para gerenciamento de múltiplos negócios.
* Isolamento de dados por negócio utilizando `businessId`.
* Autenticação JWT e controle de acesso por perfil.
* APIs REST com validação de dados.
* Documentação de APIs com Swagger.
* Ambiente de desenvolvimento com Docker.

#### ⚙️ Funcionalidades

* Gestão de clientes.
* Gestão de funcionários.
* Agendamentos e organização da agenda.
* Estrutura preparada para diferentes segmentos comerciais.
* Integração com inteligência artificial para geração de mensagens personalizadas.
* Planejamento de automações de comunicação com clientes.
* Desenvolvimento de recursos de gestão financeira e indicadores de negócio.

#### 🧠 Evolução do projeto

Mais do que desenvolver funcionalidades isoladas, venho trabalhando na evolução da arquitetura, segurança e organização do código, buscando construir uma aplicação preparada para crescer e atender múltiplos clientes.

O projeto envolve desafios reais de desenvolvimento SaaS, como isolamento de dados entre empresas, autenticação, organização de módulos, modelagem de banco de dados e integração entre serviços.
