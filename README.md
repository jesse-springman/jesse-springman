## 🚀 Projeto em destaque

### 🔹   Karvane — Plataforma SaaS de gestão empresarial

Plataforma de gestão e agendamento desenvolvida para atender diferentes tipos de negócios, com foco em organização, produtividade e relacionamento com clientes.

O projeto evoluiu de uma aplicação voltada para pet shops para uma estrutura mais flexível, preparada para atender diferentes segmentos comerciais.

#### 🏗️ Arquitetura e desenvolvimento

- Backend desenvolvido com NestJS e TypeScript.
- Frontend desenvolvido com Next.js e React.
- Arquitetura modular, organizada por funcionalidades e responsabilidades.
- Arquitetura multi-tenant para gerenciamento de múltiplos negócios.
- Isolamento de dados por negócio utilizando `businessId`.
- Autenticação JWT e controle de acesso por perfil.
- Banco de dados PostgreSQL com Prisma ORM.
- APIs REST com validação de dados e documentação Swagger.
- Containerização do ambiente de desenvolvimento com Docker.
- Integração contínua (CI/CD) com GitHub Actions para automação de testes.
- Testes automatizados para validação das funcionalidades.
- Tarefas agendadas (Cron) para automações e rotinas do sistema.

#### 💳 Integração com gateway de pagamentos — Asaas

Implementação de um módulo de billing para gerenciamento de pagamentos e assinaturas da plataforma.

- Integração com a API do Asaas para operações de pagamento.
- Arquitetura desacoplada por meio de contratos e abstrações de gateway, facilitando uma eventual substituição do provider.
- Separação entre regras de negócio, casos de uso e implementação específica do gateway.
- Gerenciamento de assinaturas, cobranças recorrentes e cancelamentos.
- Integração com webhooks para receber eventos de pagamento enviados pelo Asaas.
- Processamento dos eventos recebidos e atualização dos estados internos de pagamentos e assinaturas.
- Persistência dos dados de billing no PostgreSQL utilizando Prisma ORM.
- Rotinas automatizadas de conciliação de pagamentos, geração de cobranças, tratamento de inadimplência e finalização de cancelamentos.
- GitHub Actions para agendamento e execução das rotinas diárias.
- Proteção dos endpoints de automação, logs e tratamento individual de falhas.
- Consideração de idempotência, atomicidade e consistência dos dados nos fluxos financeiros.

#### ⚙️ Funcionalidades

- Gestão de clientes.
- Gestão de funcionários.
- Agendamentos e organização da agenda.
- Estrutura preparada para diferentes segmentos comerciais.
- Insights com IA para apoiar a análise e a tomada de decisões nos negócios.
- Planejamento de automações de comunicação com clientes.
- Desenvolvimento de recursos de gestão financeira e indicadores de negócio.
- Módulo de billing para gerenciamento de assinaturas e pagamentos.

#### 🧠 Evolução do projeto

Mais do que desenvolver funcionalidades isoladas, venho trabalhando na evolução da arquitetura, segurança e organização do código, buscando construir uma aplicação preparada para crescer e atender múltiplos clientes.

O projeto envolve desafios reais de desenvolvimento SaaS, como isolamento de dados entre empresas, autenticação, organização de módulos, modelagem de banco de dados, integração com serviços externos, processamento de eventos e consistência de informações financeiras.
